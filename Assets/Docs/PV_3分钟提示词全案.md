## 1. 使用方式（重要，先读这一节）

**不要让模型一次生成 3 分钟成片。** 现有视频模型在超过 10 秒后必然出现角色崩坏、规则错乱和风格漂移。正确路径：

1. **先做角色锁定**：用图像模型生成 5 张角色参考图（老板 + 红/蓝/黄/绿四名实习生）和 4 张场景 Style Frame（Bug 会议室 / 海岛 / 料理竞技场 / 城市广场）。这 9 张图是全片一致性的唯一基准，务必先定稿再动视频。
2. **再搭 Animatic**：用静帧 + 占位音效 + 旁白拼一版 3:00 动态分镜，确认每段时长和笑点位置，再生成正式视频。这一步能省掉一半以上的返工额度。
3. **逐镜生成**：每次只投喂一个镜头的提示词，生成 4–7 秒。每个镜头首尾各保留约 1 秒稳定画面供剪辑。
4. **海岛捕鱼优先用 Unity 实录**：小刀、水雷、偷鱼等未实现的能力才用 AI 补镜头，但地图布局、角色颜色、道具造型必须与 Demo 完全一致。
5. **一律输出无字干净版**：倒计时、积分、读条、道具栏、片名、字幕全部后期叠加。让模型生成文字必然出乱码。

**素材命名**：`S02_SH05_T03.mp4`（场景_镜头_第几次生成）。每条素材同时保存提示词原文、Seed、模型版本和问题记录，方便定点替换。

## 2. 全局锚点（每个镜头都必须粘贴在提示词开头）

> **【全局锚点 · GLOBAL ANCHOR】**
> 高完成度三渲二卡通 3D 游戏宣传片风格，16:9，24fps，清晰轮廓线，柔和体积光，色彩饱和明快但不过曝，玩具化人物比例（大头、短四肢、圆润造型），夸张动作喜剧表演，整体轻松搞怪，无写实暴力、无血腥、无真实伤害。
> 固定角色共五人：一名邪恶老板（高瘦中年男性，黑西装、暗红领带、后梳黑发、锐利眉眼、表情刻薄夸张），以及四名实习生，分别以**红、蓝、黄、绿**四色作为唯一识别标志，颜色贯穿服装、装备、道具光效与所属物品。所有镜头中人物的脸型、发型、服装、身高比例与配色必须完全一致，不得换脸、换色、增减人数。
> Bug 世界统一视觉：蓝色数据裂缝、悬浮像素方块、故障闪烁（glitch）、贴图错位、模型轻微穿插、半透明错误弹窗轮廓（不含可读文字）。
> 构图：主体位于画面中央安全区，画面顶部预留倒计时与积分 UI 空间，底部避免关键动作贴边。
> **禁止生成任何可读文字、数字、字幕、Logo、水印、排行榜与复杂 HUD。**
> 镜头首尾各保持约 1 秒稳定画面。

## 4. 通用负面提示词（所有镜头共用）

> **【负面提示词 · NEGATIVE】**
> 不要写实摄影风格，不要真人实拍质感；不要血腥、伤口、死亡、恐怖、真实枪械与真实斗殴；
> 不要角色换脸、换发型、换服装、换配色，不要人物数量增减，不要出现抢戏的额外路人主角；
> 不要手指畸形、多指少指、肢体粘连、脖颈扭曲、脸部融化、身体突然变形、模型严重穿模；
> 不要镜头高速旋转、无意义剧烈摇晃、过度运动模糊、焦点漂移、突然变焦；
> 不要生成可读的中文、英文、数字、字幕、片名、Logo、水印、排行榜、复杂 UI 与图标；
> 不要改变 16:9 画幅，不要把关键角色放在画面最边缘，不要在镜头结束前 1 秒内切换场景或大幅改变构图；
> **规则类禁止项**：不要同时出现多个普通捕鱼点；不要让水雷摧毁船只或让船上已捕的鱼掉落；不要把偷鱼表现为攻击船只（偷鱼只发生在敌方岛上的鱼库）；不要让搜索阶段的道具凭空消失（必须表现为被肘击打落并弹开）。

**S01_SH01**

**S01_SH02**

**S01_SH03**

**S01_SH04**
> 【粘贴全局锚点】会议室内低机位喜剧镜头。四颗发着蓝色内光的胶囊状小药丸滚落到桌面上，胶囊表面有细微的像素颗粒质感。四名实习生极不情愿地各自捏起一颗吞下，表情从抗拒变成惊恐。吞下后四人身体在1秒内急速缩小到只有巴掌大小，镜头随之快速下降到桌面高度：原本普通的键盘键帽、咖啡杯、订书机在他们身边变成建筑物一样的巨物，四个小人在巨大键帽之间站立并慌乱环顾。缩小过程用轻微的卡通挤压回弹表现，不要出现身体扭曲或融化。一个巨大键帽在镜头前掠过形成短暂遮挡。

**S01_SH05**
> 【粘贴全局锚点】桌面高度视角，缓慢推向电脑显示器屏幕。屏幕表面裂开一道明亮的蓝色数据裂缝，裂缝内部是旋转的蓝色数据漩涡，漩涡中漂浮着像素方块和半透明的错误窗口轮廓。四个缩小后的实习生被强气流卷起，四肢乱蹬、表情夸张地惊叫，按红、蓝、黄、绿的顺序依次被吸入漩涡。他们身后的会议室在镜头中被拉长变形，像被拽入隧道。整个过程蓝光为主导，明亮但不刺眼。收尾镜头停在漩涡中心，保持1秒稳定。

### 后期提示
- 老板全部台词、报错内容、"唯一转正名额"提示与片头字幕后期添加，AI 画面只保留表演和屏幕光。
- 颜色过渡链：**大屏红光 → 纸张白 → 胶囊蓝光 → 蓝色漩涡**，一路推向下一段。
- S01_SH04 的缩小瞬间是最容易出现变形瑕疵的地方，用巨大键帽擦镜硬切可以完全遮掉。
- 一致性不足时的保命顺序：**老板拍桌 > 一份通知书四只手 > 四人吞胶囊缩小**。

## 14. 总提示词（仅用于 Animatic 与整体风格参考）

> 用途：让模型理解完整故事、生成整体风格参考或分镜草稿。**不要用它直接产出成片**，最终素材仍按上面 41 个镜头逐条生成。

> 生成一支约3分钟、16:9、24fps 的四人竞争派对游戏概念 PV，片名《BUG派对》。整体采用高完成度三渲二卡通 3D 风格，清晰轮廓线、柔和体积光、玩具化人物比例、夸张动作喜剧，节奏明快搞怪，全程无写实暴力与血腥。固定角色为一名高瘦、黑西装、暗红领带、后梳黑发、表情刻薄夸张的老板，以及红、蓝、黄、绿四名实习生；所有镜头保持脸型、发型、服装、身高比例与配色一致。Bug 世界统一出现蓝色数据裂缝、悬浮像素方块、故障闪烁、贴图错位与错误界面轮廓。所有文字、字幕、倒计时、积分、读条、Logo 与 UI 留给后期，画面上下保留安全区，每个镜头首尾各留约1秒稳定画面。

> 第一段，故障会议室。大屏幕不断闪烁红色报错，黑西装老板猛拍桌面、探身指向四名紧张的实习生，把一份**唯一的录用通知书**拍在桌上——四个人只有一个转正名额。老板抛出四颗发蓝光的 Debug 胶囊，四人被迫吞下，身体急速缩小，键盘键帽与咖啡杯变成巨物，随后被电脑屏幕中的蓝色数据漩涡吸入。

> 第二段，Bug 化的会议室搜索。四人掉进同一间被数据侵蚀的会议室：桌椅悬浮、白板漏蓝色数据流、饮水机吐像素方块。门砰地关闭，倒计时开始。四人扑向抽屉、饮水机、天花板夹层和投影仪箱疯狂翻找，掉落的是渔网、小刀和水雷。**每人最多能带走两件，但可以用手肘互相撞击，把对手已经拿到的道具直接打飞**——蓝色肘击红色，红色怀里的渔网脱手旋转落地。最终四人手里的道具数量各不相同，被蓝色传送门逐个吸走。这个搜索段在全片中出现三次，房间结构完全一致，只更换掉落主题（捕鱼 / 料理 / 警察），每次的肘击笑点比上一次更夸张。

**节奏检查**：把这 12 个点标在 3:00 时间轴上，任意相邻两点的间隔**不应超过 20 秒**。如果某处出现超过 20 秒的空白，说明那一段在讲规则而没有给情绪，必须补一个反应镜头或表情特写。

### 15.2 五种放大尖叫度的通用手法

1. **反应镜头永远比动作镜头值钱**。挨打的那张脸比打人的那只手好看。每个恶意笑点后面都要跟半秒的受害者表情特写——这半秒可以从原镜头里裁切，不用额外生成。
2. **慢动作 + 定格 + 静音**。S1C_SH03 是模板：动作放慢 → 最高点定格 → 声音全部掐掉 → 一记重鼓点硬切。这个组合在任何素材上都有效。
3. **擦镜硬切**。渔网、火焰、番茄、人群、纸钞、键帽都可以贴着镜头掠过，用来遮住 AI 生成的瑕疵，同时让剪辑显得干净利落。
4. **重复三次的规则会变成笑点**。三次搜索段用同一个机位、同一段传送动画，观众第三次看到时会预判"又要打起来了"——预判本身就是笑点。
5. **音效承担一半的尖叫度**。肘击用夸张"砰"+弹簧音；踩雷用滑稽气泡爆音；抓错人用错误提示音"噗"；金色芯片用清亮上扬音。**不要用真实撞击声**，会立刻破坏轻松基调。

## 17. 生成参数建议与故障排查

### 17.1 建议参数
- **单镜时长**：4–6 秒。超过 7 秒角色崩坏率显著上升。
- **首帧控制**：所有关键镜头都用图生视频（首帧图），而不是纯文生视频。首帧图由图像模型基于角色参考图生成，一致性提升最明显。
- **同一场景锁定 Seed**：S1A / S1B / S1C 三段必须复用同一个 Seed 与同一张房间首帧图，只改提示词里的掉落物描述。
- **每镜生成 3 个 Take** 起，挑最好的那个。预算按 41 镜 × 3 Take ≈ 123 次生成来估。

### 17.2 常见问题对照表

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 角色换脸 / 换色 | 提示词角色描述不足或时长过长 | 缩短到 4 秒；改用首帧图生视频；把颜色词写进动作句而非只写在锚点里 |
| 画面出现乱码文字 | 提示词里出现了引号包裹的文字内容 | 删除一切文字描述，改成"不含可读文字的界面轮廓" |
| 动作看不懂 | 一个镜头塞了两个以上核心动作 | 拆成两个镜头，每镜只做一件事 |
| 出现多个捕鱼点 | 模型倾向于填满画面 | 在提示词里显式写"整个画面中只有这一处冒泡区域，其他水面平静" |
| 肘击看起来像打架 | 缺少卡通化限定 | 补"卡通式夸张肘击、爆出白色卡通冲击线、无真实伤害" |
| 转场生硬 | 没有指定收尾状态 | 每条提示词结尾都写明"收尾停在××画面，保持1秒" |
| 人数变多 | 背景人群失控 | 负面提示词强化，并把主体人数写进正面提示词第一句 |
