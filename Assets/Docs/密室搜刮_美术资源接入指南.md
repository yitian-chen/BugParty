# 美术资源接入指南

面向美术与技术美术。**替换资源全程不需要改玩法脚本。**

---

## 一、先看结论：哪些能直接换，哪些要动手

| 类别 | 状态 | 操作方式 |
|---|---|---|
| 道具模型 | ✅ 已接线 | 填 `ItemDefinition.worldPrefab` |
| 角色模型 | ✅ 已接线 | 填 `RoomConfig.characterPrefabs[0..3]` |
| 阴影 / 容器 / 碎片 / 地砖 | ✅ 已接线 | 填 `RoomConfig` 对应槽位 |
| 角色动画 | ✅ 桥接已备 | 挂 `PlayerAnimatorBridge` + 建 Animator 参数 |
| 音效 | ✅ 总线已备 | 填 `RoomAudioVfx` 槽位 |
| 粒子特效 | ✅ 总线已备 | 填 `RoomAudioVfx` 槽位 |
| 场景墙体 / 家具 | ⚠️ 半自动 | 建场后在 Hierarchy 里手动换 Mesh |
| UI / HUD | ❌ 需重写 | 目前是 `OnGUI` 代码绘制，见第七节 |

> 所有槽位**留空即回退到程序生成的占位体**。可以一个一个换，不必等资源齐了才能跑。

## 二、角色模型（最常用）

### 模型规格要求

| 项 | 要求 |
|---|---|
| 朝向 | 面朝 **+Z** 轴 |
| 原点 | 脚底在 `y = 0` |
| 身高 | 约 **1.5 米**（匹配 `CharacterController.height = 1.5`） |
| 半径 | 肩宽不超过 **0.76 米**（`radius = 0.38`） |
| 碰撞体 | **不需要**。建场时会自动全部移除 |

身高不符不用改模型，缩放 Prefab 根节点即可。

### 操作步骤

1. 菜单 **BugParty2D ▸ Create Config Assets Only**，会生成 `Assets/BugParty2D/Config/RoomConfig2D.asset`
2. 选中它，找到 **美术资源替换** 分组
3. `Character Prefabs` 有 4 个槽位，按 **红 / 蓝 / 黄 / 绿** 顺序拖入角色 Prefab
4. 菜单 **BugParty2D ▸ Build Room Scene** 重建场景

建场工具会自动完成：

- 实例化 Prefab 挂到 `Visual` 节点下
- **移除模型自带的所有 Collider**（移动由 CharacterController 接管，留着会打架）
- 取第一个 `SkinnedMeshRenderer` 作为染色目标（队伍配色、受击闪白用）
- **若模型带 Animator，自动挂上 `PlayerAnimatorBridge` 并完成接线**

### 四个挂点

替换模型后这些挂点依然生效，位置可在 Hierarchy 里微调：

| 挂点 | 用途 | 默认位置 |
|---|---|---|
| `Visual` | 视觉根节点，受击翻滚动画旋转它 | `(0, 0, 0)` |
| `HandAnchor` | 道具在手里的位置、掉落道具的起点 | `(0.35, 0.85, 0.3)` |
| `ElbowOrigin` | 肘击判定球的中心 | `(0, 0.8, 0.1)` |
| `Shadow_<色>` | 落地阴影，**不是玩家子物体** | 跟随 XZ |

> 阴影刻意不作为子物体——否则转身时方形阴影会明显打转。它由 `PlayerActor.UpdateShadow()` 每帧同步位置，并按离地高度缩放变淡。**这是 2D 俯视判断高度的核心线索，别删。**

## 三、角色动画

### 需要的 Animator 参数

参数名必须一致，写在 `PlayerAnimatorBridge.cs` 顶部的常量里，要改名改那里。

| 类型 | 名称 | 含义 |
|---|---|---|
| Float | `Speed` | 水平速度，默认归一化到 0~1 |
| Float | `VerticalSpeed` | 垂直速度，正=上升 负=下落 |
| Bool | `Grounded` | 是否在地面 |
| Bool | `Searching` | 是否在翻箱（持续状态） |
| Bool | `Staggered` | 是否处于被击退硬直 |
| Trigger | `Jump` | 起跳瞬间 |
| Trigger | `Land` | 落地瞬间 |
| Trigger | `Elbow` | 挥肘瞬间 |
| Trigger | `GetHit` | 被肘击命中 |
| Trigger | `Pitfall` | 踩空掉洞 |

### 最小可用配置

**先只做 `Speed` + `Grounded` + `Jump` 三个**，就已经能看出效果。缺少的参数不会报错——桥接层用 `HasParameter` 做了缓存与保护，只驱动实际存在的参数。

### 调参

- `speedNormalizeMax`：跑步动画对应的速度上限。填 `0` 则输出原始速度值（适合 Blend Tree 用真实速度做阈值）
- `speedDamping`：默认 `0.08`。松开摇杆时动画不会瞬间切断

## 四、音效与特效

场景里已自动生成 **`AudioVfx`** 物体，挂着 `RoomAudioVfx`。所有槽位留空则不播。

### 音效槽位

搜索开始 / 搜索被打断 / 拾取道具 / **稀有道具专属** / 肘击命中 / 道具被打落 / 起跳 / 落地 / **重落地** / 地板开裂 / 地板塌陷 / 踩空 / 全塌陷

两个值得注意的：

- **`sfxTileCracking`（地板开裂）建议一定要有。** 这是玩家躲开塌陷的关键听觉线索——1.8 秒预警期里，没声音的话玩家很可能没注意到红光。
- **`sfxItemRare`** 填了之后，搜到稀有道具会优先播它，是给玩家的即时正反馈。

### 警报循环音

`alarmLoop` 拖一个 AudioSource 进去，会随倒计时**自动升高音调与音量**：

```
alarmPitchRange   0.85 → 1.35
alarmVolumeRange  0.25 → 0.85
```

搜索阶段自动播放，其他阶段自动停。

### 粒子槽位

肘击撞击 / 拾取闪光 / 地板开裂碎屑 / 塌陷尘土 / 重落地扬尘

生成后按 `vfxLifetime`（默认 2.5 秒）自动销毁，不用自己管回收。

## 五、道具模型

选中 `Assets/BugParty2D/Config/Items/` 下的任意 `ItemDefinition`，填 **外观 ▸ World Prefab**。

留空时用 `placeholderColor` + `placeholderSize` 生成彩色方块；`isRare = true` 的占位体会自动混入金色。

**填了 Prefab 后 `placeholderColor` 就不再生效**，稀有感需要美术自己表达。

Prefab 不需要自带 Rigidbody 和 Collider，`WorldItem.SpawnDropped()` 会自动补上（质量 0.3、阻力 0.45）。

## 六、场景物件

### 已接线的槽位

`RoomConfig` 里：`containerPrefab`（搜索容器）、`debrisPrefab`（天花板碎片）、`floorTilePrefab`（地板砖）、`floorMatSolid` / `floorMatCracking`（地板两态材质）、`shadowMaterial`

> `floorTilePrefab` **必须是 1×1 单位大小**，建场时会按格子尺寸缩放。

### 墙体与家具需要手动换

这部分是建场工具用 Cube 直接生成的，没做 Prefab 槽位。建完场后在 Hierarchy 里找：

```
BugParty2D_Room/
├── Room/          墙体、天花板
├── Terrain/       会议桌、矮柜、高台、斜坡
├── BugProps/      悬浮家具、数据裂缝
└── Alarm/         警报灯
```

替换方式：保留 GameObject 和它身上的组件（`BugAmbience` 等），只把 `MeshFilter.mesh` 和 `MeshRenderer.material` 换掉。

**碰撞体必须保留**——`Terrain/` 下的物件靠 Collider 支撑玩家站立，删了会掉下去。

## 七、UI 目前不可直接替换

`RoomHUD.cs` 用 `OnGUI()` 代码绘制，这是为了让 Demo 零依赖跑起来，**不适合作为正式 UI**。

要做正式 UI 建议：新建 Canvas，写一个新的 HUD 脚本订阅 `RoomEvents`，然后把 `RoomHUD` 组件禁用。事件已经够用了：

```csharp
RoomEvents.OnTimerTick += t => timerText.text = Mathf.CeilToInt(t).ToString();
RoomEvents.OnInventoryChanged += p => RefreshSlots(p);
RoomEvents.OnPhaseChanged += phase => ShowBanner(phase);
```

## 八、验收清单

替换资源后逐条确认：

1. 四名角色外观正确，颜色区分清晰
2. 移动时朝向跟着转，不会侧着走
3. 跳上会议桌后**阴影明显变小变淡**
4. 从高台落下有重落地反馈
5. 肘击时攻击方有挥肘动作，受击方有被打反应
6. 道具被打落后在地上打转，能走过去捡起
7. 地板开裂时**有声音**，不只是变红
8. 倒计时最后 10 秒警报音明显更急更响
9. 终局全塌陷时四人翻滚下坠动作正常
10. 控制台无 `NullReferenceException`

第 3、7 两条最容易被忽略，但它们分别是「高度可读性」和「塌陷可预判性」的成立条件。

## 九、常见问题

**角色陷进地板或浮空** — Prefab 原点没在脚底。调整模型根节点或在 `Visual` 下微调 Y。

**角色卡住不动** — 模型自带 Collider 没删干净。建场工具会自动移除，但运行时动态生成的碰撞体需手动处理。

**动画不播** — 检查三点：模型上有 Animator、Animator Controller 已赋值、参数名与第三节表格完全一致（大小写敏感）。

**换了模型后受击不闪白** — `bodyRenderer` 取的是第一个 `SkinnedMeshRenderer`。多材质模型可能取错，建场后在 Inspector 里手动指定 `PlayerActor.bodyRenderer`。

**阴影是方的** — 填 `RoomConfig.shadowMaterial`，用带软边圆形 alpha 的材质。

**升级 Unity 6 后报 `drag` 不存在** — 改成 `linearDamping`，只有 `PlayerActor.cs` 和 `WorldItem.cs` 两处。
