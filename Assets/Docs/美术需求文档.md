### 1.2 场景类 ★（新增）

| 文件名 | 内容 | 说明 |
|---|---|---|
| ★ `mdl_island_sand.fbx` | 圆形/椭圆形沙滩底座 | 直径约 8m，边缘做圆角磨圆。中央凹陷用于放平台。共用一套 mesh，四个岛通过 `mat_island_*` 变色 |
| ★ `mdl_island_platform.fbx` | 岛屿上的木质卸鱼台 | 直径 2m 木盘 + 4 根支柱，顶面平坦（要能堆鱼）。≤300 tris |
| ★ `mdl_island_deco_palm.fbx` | 装饰用小椰树 | 高 3-4m，一个模型足够（可复用 4 岛），带轻微弯曲，1-2 张叶子 |
| ★ `mdl_island_deco_rock.fbx` | 岸边装饰小石头 | 3-4 个变体在同一 FBX 中，按 SubMesh 区分 |

|---|---|

## 11. 命名 / 规格约束（一致性红线）

- 命名：`类型_名称.扩展`，小写下划线，英文（例：`fx_frenzy_start.prefab`）
- 单位：米，Y 向上，Z 前
- FBX：Apply Root Motion=false；`useFileScale=false, globalScale=1`（`unity_asset_import` 后请在 Import Settings 面板确认）
- 材质命名：`mat_<类别>_<变体>.mat`
- 一个模型 = 一个 mesh + 一张（或共享的）材质。多变体走**材质变体**而非多份 mesh。
- 音频：`.wav` 存源、Unity 里勾选 Load Type=Streaming（BGM）或 Decompress on Load（短 SFX）由工程配置，不需美术处理。
