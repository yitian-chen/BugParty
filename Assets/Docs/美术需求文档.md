## 1. 3D 模型（FBX，米单位，Y 向上，≤500 tris/个，Low-Poly）

| 文件名 | 内容 |
|---|---|
| `mdl_player.fbx` | 主角人偶：卡通 Q 版比例（约 1.6m 高），Humanoid 骨架（≤30 骨骼），大头小身，双手可持道具。带手部挂点 `hand_R`。共用一套 mesh，通过 4 色材质变体区分玩家（红/蓝/绿/黄）。≤1500 tris |
| `mdl_raft.fbx` | 木筏：2m 方形木板 + 桅杆插旗（旗色跟随玩家色） |
| `mdl_fish_common.fbx` | 普通鱼，长 ~0.4m，蓝白色 |
| `mdl_fish_golden.fbx` | 金色鱼，长 ~0.5m，鳍略夸张 |
| `mdl_item_net.fbx` | 渔网：长杆 + 圆网 |
| `mdl_item_mine.fbx` | 水雷：球体 + 犄角 |
