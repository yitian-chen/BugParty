关卡：Bug 海岛捕鱼赛
补充内容：
镜头：俯视角；场景：海洋，四个角为岛屿，是每个人放鱼的区域。
整个环节是三分钟 180s（30秒刷新一次，以冒泡泡的区域的形式呈现，共计出现5次普通捕鱼点+一次特殊捕鱼点，30秒后捕鱼点消失）
普通捕鱼点只有普通的积分鱼，一个捕鱼点三条，时间过了消失或3条鱼捕完消失；特殊捕鱼点里所有的鱼都是高积分鱼（金色），没有数量限制。
获胜条件：三分钟倒计时结束后，自己的岛上的鱼的数量最多的获胜。
完整游戏体验：
游戏开始，各自带有道具（道具格有两格），321 倒计时后开始行动，玩家（和他的小木筏）在各自的小岛附近复活，此时捕鱼点同步刷新，页面上方显示；
从地图最左上角到右下角的直线移动的时长是15s，长边12s，短边9s。
捕鱼的时候不可以干扰别人，除非有破坏类道具（例如小刀）。
小刀只能在捕鱼读秒的过程中使用，距离必须很近
鱼雷是地雷，隐身，触及原地停止5s，被炸者可重新拾取鱼雷使用。
最后一个捕鱼点刷新的时候，移动速度翻倍，捕鱼效率翻倍。

捕鱼点：30s刷新一次，最后一个捕鱼点放最中间，里面的鱼积分更高；每个捕鱼点三条，捕完捕鱼点消失；在页面上方有30s倒计时，
木筏上最多放两条鱼，岛上数量不限

每个人最多携带两个道具，玩家可以从捕鱼点捕鱼，也鼓励玩家去其他玩家的岛上偷鱼。

四名玩家分别出生在四座小岛附近，中间为公共捕鱼区。
游戏规则：
1. 鱼冒出来的频率是多少？
2. 每次冒出来持续多长时间？（频率的意思就是每次最多会出现几个冒泡区域）
3. 这个冒泡区域范围有多大？
4. 里面会有几条鱼？
   道具：
   1.破坏类
   小刀（破坏渔网，可重复使用，耐久三次一局）、水雷（破坏船，只能使用一次，被炸的人可以拣取使用水雷）
   2.捕鱼类
   大渔网（一次两只，5s读取时间）、小渔网（一次一只，5s读取）、徒手（1次1条，8s读取）

渔船一次能运两条鱼；
水中刷新普通鱼、稀有鱼。玩家需要捕鱼得分，同时利用搜索阶段（暂时不做）获得的道具争抢资源或干扰其他玩家。
